# Security Policy

As a U.S. Government agency, the General Services Administration (GSA) takes
seriously our responsibility to protect the public's information, including
financial and personal information, from unwarranted disclosure.

## Reporting a Vulnerability

Software developed by the U.S. General Services Administration (GSA) is subject
to the [GSA Vulnerability Disclosure Policy](https://www.gsa.gov/website-information/vulnerability-disclosure-policy).

Please consult that policy for:

* How to submit a report if you believe you have discovered a vulnerability.
* GSA's coordinated disclosure policy.
* Information on how you may conduct security research on GSA developed
  software and systems.
* Important legal and policy guidance.

Do not report a vulnerability in a public issue or pull request, and do not
include customer documents or credentials in a report.

## Supported Versions

Only the `main` branch receives security updates. When using this code or
reporting vulnerabilities, please use the current `main`.

| Version (Branch) | Supported          |
| ---------------- | ------------------ |
| main             | :white_check_mark: |
| other            | :x:                |
